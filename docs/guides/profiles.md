# プロファイルとルック

設定画面のトップでは、品質プロファイルでどれだけ重い手法を使うかを、ルックで光と色の作り方を選びます  
2 つは別々で、プロファイルを変えてもルックは変わりません

## プロファイル

軽い順に 9 段あり、既定は「高」です

| プロファイル | 中身 |
|---|---|
| 低 | floodfill の光だけで照らす、光源シャドウ・GI・反射・雲・ボリューメトリックライトなどを止める |
| 中 | 光源シャドウ (部分形状とエンティティの遮蔽を含む) と手持ち光源のレイを使う |
| 高 (最軽量) | 「高」と同じ手法と見た目で、内部の解像度とサンプル数をいちばん下げる |
| 高 (軽量) | 「高 (最軽量)」より少しだけ戻す |
| 高 | 接触影・RSM の GI・光源トレース 4 本・被写界深度など |
| 最高 | 「高」にスクリーンスペースの GI、多めのサンプル、水の屈折のレイトレース、コースティクス、POM を足す |
| 極限 (軽量) | ボクセル GI とボクセルで補う反射を使い、範囲と解像度は「最高」と同じ |
| 極限 (バランス) | 「極限」の範囲のまま、光源のトレース・GI・雲・ボリューメトリックライトを半分の解像度にする |
| 極限 | ボクセル GI で、すべてフル解像度、いちばん重い |

まず「高」で動かして、フレームが足りなければ 1 段ずつ下げます  
「高」「最高」「極限 (軽量)」はほぼ同じ重さで、「極限」は「高」の約 2.5 倍です (数字は [performance.md](performance.md))

「高 (軽量)」「高 (最軽量)」は、下げた分を時間方向の積み重ねとデノイズで補います  
止まった場面ではほとんど差が出ませんが、素早く動いたときや光が変わった直後にノイズが残りやすくなります  
「極限 (軽量)」「極限 (バランス)」は、ボクセル GI とボクセルで補う反射の見た目を軽く使うための段です  
雲の形と陰影は「中」から上のどれでも同じで、変わるのは細かいノイズの量と重さだけです

### 選んだあとに個別に変える

プロファイルは個別の設定をまとめて書き換えるだけなので、選んだあとで 1 つずつ変えて構いません  
ただし、もう一度プロファイルを選ぶとそのプロファイルの値に戻ります  
細かく作り込んだあとはプロファイルを選び直さないようにします

プロファイルごとの全部の値は [../architecture.md](../architecture.md) の「設定とプリセット」にあります

## ルック

`LOOK_PRESET` (既定「ビビッド」)

| ルック | 見た目 | 向く場面 |
|---|---|---|
| カスタム | プリセットにしかない値を自分で決める (下の「カスタムルック」) | 作り込みたいとき |
| ナチュラル | 素朴なマイクラらしさを残した、目の疲れない見た目 | 長く遊ぶとき |
| ビビッド | 日向と日陰の明るさの差、日向の暖色と日陰の青緑、草の照り返しの緑、白近くまで伸びる明部、彩度とブルームは控えめ | 景色を見て回るとき |
| デイライト | ビビッドの光に、濃い青空・緑の草・日向の凹凸の陰影を足した晴れた日中 | 昼の景色 |
| 夏の青空 | 明るく軽い真夏の日中、地平線の近くまで濃い青空と暖かい日差し | 昼の景色 |
| ゴールデンアワー | 一日中、夕方前の低い日差しのような暖かさと柔らかいブルーム | 暖かい雰囲気 |
| ティール & オレンジ | 暗い側と草を青緑、明るい側と木・土を橙に寄せる映画の定番 | 撮影 |
| ブリーチバイパス | 色の抜けた硬い絵、コントラストが強く長く遊ぶと目が疲れやすい | 撮影 |
| クロスプロセス | 黄緑に転んだ明部と青い暗部、色とコントラストが強い | 撮影 |
| ゲーム (鮮やか) | 色をはっきり出し、暗い所も見やすい | 暗い所を見やすくしたいとき |

### ルックごとの値の早見表

ルックが決める値のうち、見え方に効く主なものです  
「掛ける」は自分の設定にさらに掛かる倍率、「足す」は足される値で、ナチュラルは明部の伸びだけが 1.1 で、ほかは掛ける値が 1、足す値が 0 なので各設定の値がそのまま効きます

| ルック | 空の環境光の強さ | 日向の暖かさ | 照り返しの強さ / 色の濃さ | 露出 (足す、EV) | 明部の伸び | 暗部の持ち上げ | 彩度 (掛ける) | ブルーム (掛ける) |
|---|---|---|---|---|---|---|---|---|
| ナチュラル | 1 | 0 | 1 / 1 | 0 | 1.1 | 0 | 1 | 1 |
| ビビッド | 0.8 | 0.85 | 1.6 / 1.5 | -0.15 | 1.6 | 0.5 | 1.1 | 1.2 |
| デイライト | 0.8 | 0.85 | 1.6 / 1.5 | -0.15 | 1.5 | 0.5 | 1.05 | 1.1 |
| 夏の青空 | 0.85 | 0.7 | 1.6 / 1.5 | 0.1 | 1.4 | 0.5 | 1.08 | 1.2 |
| ゴールデンアワー | 0.85 | 1 | 1.5 / 1.4 | -0.1 | 1.3 | 0.5 | 1.05 | 1.5 |
| ティール & オレンジ | 0.8 | 0.85 | 1.5 / 1.3 | -0.15 | 1.4 | 0.5 | 0.95 | 1.2 |
| ブリーチバイパス | 1 | 0 | 1 / 1 | 0 | 1 | 0 | 0.6 | 1 |
| クロスプロセス | 0.9 | 0.3 | 1.3 / 1.2 | -0.1 | 1.3 | 0.25 | 1.2 | 1 |
| ゲーム (鮮やか) | 0.9 | 0.6 | 1.7 / 1.6 | -0.05 | 1.4 | 0.5 | 1.12 | 1.2 |

デイライトから下のルックは、これに加えて色と階調の多くをカラーグレーディングの基準として持ちます  
全部の値は `shaders/lib/common/look_presets.glsl` にあります

ビビッドは、そのほかに空の色の彩度が 1.08、空の環境光の彩度が 1.1 倍、空の光の遮蔽が 1.6 倍、ブルームの広がりが 0.75、フォグの濃さが 1.15 倍です  
空の光の遮蔽は SSGI とボクセルレイトレースのときだけ効き、既定の 0.5 に掛かって 0.8 になるので、洞窟の中や軒下に向きの無い空の青が回り込みにくくなります

### ルックとほかの設定

彩度・コントラスト・ブルーム・ブルーミーフォグ・空の光の遮蔽・空の環境光の彩度・フォグの濃さは、ルックの値に自分の設定が掛かり、露出補正は足されます  
たとえば彩度を 1.2 にすると、ナチュラルでは 1.2 のまま、ビビッドでは 1.1 が掛かって 1.32 になります  
カラーグレーディングの設定もルックの上に重なり、デイライトから下のルックは色と階調の多くをグレーディングで作っています

GI の方式によって照り返しの出方が違います  
RSM は照り返しの色が濃く出るので、ビビッドの「照り返しの色の濃さ」は RSM のときに半分だけ掛けています  
ルックを見比べるときは GI の方式 ([shadows-gi.md](shadows-gi.md)) をそろえます

### カスタムルック

ルックを「カスタム」にしたときだけ、「ポストプロセス」>「色」>「カスタムルック」の 9 つが効きます  
既定値はナチュラルと同じです

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| 空の環境光の強さ (`LOOK_C_SKY_AMBIENT`) | 1.0 | 0.5〜1.5 | 日陰を照らす空の光、下げると日向と日陰の差が開く (空そのものの明るさは同じ) |
| 空の色の彩度 (`LOOK_C_SKY_SATURATION`) | 1.0 | 0.8〜1.3 | 空の青の濃さ |
| 日向の暖かさ (`LOOK_C_SUN_WARMTH`) | 0.0 | 0.0〜1.0 | 太陽の直射の光だけを暖色に寄せる、空・雲・太陽の色は同じ |
| 照り返しの強さ (`LOOK_C_BOUNCE`) | 1.0 | 0.5〜3.0 | GI のレイが当たった面からの光、空の光は変えない |
| 照り返しの色の濃さ (`LOOK_C_BOUNCE_SATURATION`) | 1.0 | 0.8〜2.0 | 上げると草の照り返しで日陰が緑がかる |
| 明部の伸び (`LOOK_C_HIGHLIGHT`) | 1.1 | 0.8〜2.0 | 中間グレーより明るい所の差を広げる |
| 暗部の持ち上げ (`LOOK_C_DARK_LIFT`) | 0.0 | 0.0〜1.0 | 2.2 乗で表示するモニターで黒くつぶれる暗部を戻す |
| ブルームの広がり (`LOOK_C_BLOOM_SPREAD`) | 0.82 | 0.5〜0.9 | 下げるほど光の近くに締まったにじみ |
| 晴れのブルーミーフォグ (`LOOK_C_BLOOM_FOG_CLEAR`) | 0.35 | 0.0〜1.0 | 晴れの日に遠景に掛かる広いにじみの割合 (雨では 1) |

照り返しの 2 つは GI の照り返しに掛けるので、GI が OFF のときは効きません

## LUT

`LOOK_LUT` (既定「なし」) は、最後に掛ける色の 3D LUT です  
トーンマップ後の表示の色 (sRGB) に、ルックとカラーグレーディングのあとで掛かります

| LUT | 色の傾向 |
|---|---|
| なし | 何もしない |
| ユーザーの LUT | `shaders/textures/look/user_lut.png` を差し替えて使う (同梱の画像は色を変えない) |
| 日向と日陰の色の割れ | 日向を暖色、日陰を青緑に、明るい緑を黄緑へ、空の青を少し深く |
| フィルム | コントラストを少し下げ、明るい所を暖色に寄せて彩度を落とす |
| Portra 風 | 低めのコントラスト、少し浮いた黒、控えめで暖かい色 |
| Ektar 風 | 鮮やかな赤と青、締まったコントラスト |
| Vision3 500T 風 | タングステン用の映画フィルムを昼に使ったような青み、柔らかい階調 |
| Velvia 風 | 高い彩度とコントラスト、濃い青空と緑 |
| Provia 風 | 素直で少し鮮やか、少し冷たく澄んだ白 |
| Eterna 風 | 落ち着いた低い彩度と柔らかいコントラスト |

「LUT の強さ」(`LOOK_LUT_STRENGTH`、既定 1.0、0.0〜1.0) で元の色と混ぜます  
効きが強いと感じたら 0.5 前後から試します

フィルム風の LUT (Portra 風から下) は、各社が公開している特性の説明をもとにした近似で、メーカーの LUT やデータは使っていません  
LUT は最後に掛かるので、ルックを変えるとその上で見え方が変わります  
色を作り込むなら、ルックとカラーグレーディングを先に決めて、LUT は仕上げに足すほうが戻しやすいです  
強いルック (ブリーチバイパス・クロスプロセス) と Velvia 風のような強い LUT を重ねると、色とコントラストが強くなりすぎます

### 自分の LUT を使う

`shaders/textures/look/user_lut.png` を自分の LUT に置き換えて、LUT を「ユーザーの LUT」にします  
同梱の `user_lut.png` は何も変えない恒等の LUT です

| 作り方 | 手順 |
|---|---|
| 画像編集ソフトで作る | `user_lut.png` (1024x32) を開き、色調補正 (トーンカーブ・色相・彩度など、ぼかしや変形はしない) を掛けて同じ名前で保存する、ゲームの撮影に同じ補正を掛けたときと同じ色になる |
| `.cube` から作る | DaVinci Resolve・Photoshop などの 3D LUT を `uv run tools/gen_look_lut.py from-cube my.cube --out shaders/textures/look/user_lut.png` で変換する、入力は sRGB の表示値 (0〜1) の LUT を想定している |
| 撮影した画面で試す | `uv run tools/gen_look_lut.py preview --lut my.cube --in shot.png --out out.png` |

画像は 32x32x32 の LUT を、青の段ごとに 32x32 の板を横に 32 枚並べた 1024x32 の PNG です  
各板の x が赤、y が緑 (上の行が緑 0) です
