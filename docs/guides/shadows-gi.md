# 影と GI

太陽と月の影、アンビエントオクルージョン (AO)、グローバルイルミネーション (GI、照り返し) の画面です  
たいまつなど設置した光源の影は [block-light.md](block-light.md) にあります

## 太陽と月の影

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| 影の解像度 (`shadowMapResolution`) | 4096 | 1024〜8192 | 影マップの細かさ、上げると縁がくっきりするが重く VRAM も使う |
| 影の距離 (`shadowDistance`) | 192 | 64〜1024 | 影を出す距離 (ブロック)、同じ解像度なら伸ばすほど影が粗くなる |
| 影のフィルタ (`SHADOW_FILTER`) | PCSS | ハード / PCF / PCSS | 縁の作り方、PCSS は影を落とす物から遠いほど縁が柔らかい |
| 影のサンプル数 (`SHADOW_SAMPLES`) | 16 | 4〜32 | 柔らかい縁のなめらかさ、少ないとざらつく |
| 影の柔らかさ (`SHADOW_SOFTNESS`) | 1.0 | 0.0〜4.0 | 縁のぼかしの倍率 |
| 太陽の影の濃さ (`SUN_SHADOW_STRENGTH`) | 1.0 | 0.0〜1.0 | 0 で影なし、1 で完全な影、雲の影は変わらない |
| 月の影の濃さ (`MOON_SHADOW_STRENGTH`) | 1.0 | 0.0〜1.0 | 月とエンドの光が落とす影 |
| 太陽の軌道の傾き (`sunPathRotation`) | -30 | -60〜60 | 太陽と月の通り道の傾き (度)、0 がバニラと同じ |

解像度と距離は組で考えます  
距離を伸ばすなら解像度も上げないと影が粗くなり、近くだけきれいに見たいなら距離を縮めます  
影の距離は、ボクセル範囲の半径 (64 / 96 / 128 / 192) 以上にしておかないと境目が見えることがあります

PCSS は縁が自然ですが、サンプルが足りないと縁がざらつきます  
ざらつくときはサンプル数を上げるか、フィルタを PCF にします

軌道の傾きを 0 から離すと、昼でも影が真下に落ちなくなり、時刻ごとの影の向きと長さが変わります

「影描画の最適化」(`shadowDistanceRenderMul`、既定 ON) は、影に描く地形を影の距離の内側に絞ります  
遠くの影が欠けて見えるのでなければ ON のままにします

### 色と細部

| 設定 | 既定 | 変わるもの |
|---|---|---|
| 色付きの影 (`SHADOW_COLORED`) | ON | 色ガラスや水が色の付いた日光の影を落とす |
| 色ガラスを通る日光の色 (`SHADOW_COLORED_SATURATION`) | 1.5 | 0.0〜3.0、色付きの影と光芒の色の濃さ、0 で色なし (暗くなるだけ)、1 でガラスの色 |
| エンティティの影 (`ENTITY_SHADOWS`) | ON | モブの影 |
| ブロックエンティティの影 (`BLOCK_ENTITY_SHADOWS`) | ON | チェストや看板などの影 |
| エンティティの影の距離 (`entityShadowDistanceMul`) | 0.5 | 0.25〜1.0、エンティティを影に描く距離の倍率 |
| 接触影 (`SCREEN_SPACE_SHADOWS`) | ON | 影マップでは出ない細かい影をスクリーンスペースで補う |

軽くするつもりでエンティティの影を切っても、ブロックライトの「エンティティによる遮蔽」かエンティティ光源が ON なら、影パスでエンティティを描く処理は残ります

## アンビエントオクルージョン

| 設定 | 既定 | 範囲 |
|---|---|---|
| アンビエントオクルージョン (`AO_MODE`) | GTAO | OFF / SSAO / GTAO |
| AO の強さ (`AO_STRENGTH`) | 1.0 | 0.0〜3.0 |

角や隙間の間接光を暗くして、物が接する所に立体感を出します  
GTAO のほうが自然で、軽い SSAO はプロファイル「中」で使っています  
AO と GI を両方 OFF にすると、そのパスごと止まります

## GI

`GI_MODE` (既定「RSM」) は、光が面で跳ね返って日陰や室内を柔らかく照らす照り返しの方式です

| 方式 | 特徴 | 使っているプロファイル |
|---|---|---|
| OFF | 照り返しなし、いちばん軽い | 「低」「中」 |
| RSM | 太陽の影マップを使う、照り返しの色が濃く出る | 「高」の 3 つ |
| スクリーンスペース | 画面に映っている物から照り返しを求める | 「最高」 |
| ボクセルレイトレース | ボクセルの中でレイを飛ばす、いちばん自然でいちばん重い | 「極限」の 3 つ |

GI の強さは、同じ値ならどの方式でも近い明るさになるよう方式ごとに効きを変えてあるので (ボクセル 1 倍、RSM 0.75 倍、スクリーンスペース 0.5 倍)、方式を変えても明るさを合わせ直さずに済みます  
ルックの「照り返しの強さ」は GI の強さにさらに掛かります ([profiles.md](profiles.md))

### 明るさと色

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| GI の強さ (`GI_STRENGTH`) | 2.0 | 0.0〜8.0 | 照り返しの強さ (スクリーンスペースとボクセルでは空の光も)、上げると日陰・下向きの面・室内が明るい |
| 空の光の照り返し (`GI_SKY_BOUNCE_STRENGTH`) | 1.25 | 0.0〜3.0 | 太陽・月・空の光が当たった面で照り返す量、上げると窓から差した光で部屋が明るい |
| 空の光の照り返しの色 (`GI_SKY_BOUNCE_SATURATION`) | 1.3 | 0.0〜3.0 | 当たった面の色 (赤いカーペットなど) が乗る濃さ、0 で灰色 |
| ブロックライトの照り返し (`GI_BLOCK_BOUNCE_STRENGTH`) | 1.25 | 0.0〜3.0 | ブロックライトが GI のレイの当たった面などで照り返す量 |
| ブロックライトの照り返しの色 (`GI_BLOCK_BOUNCE_SATURATION`) | 1.3 | 0.0〜3.0 | その色の濃さ |
| 多重反射 (`GI_MULTI_BOUNCE`) | 1.0 | 0.0〜1.0 | 前のフレームの GI を返して何度も跳ね返らせる量、0 で 1 回だけ |
| 空の光の遮蔽 (`GI_SKY_OCCLUSION`) | 0.5 | 0.0〜1.0 | 空の光を GI のレイで遮る割合、スクリーンスペースとボクセルだけ |
| 地面の照り返しの置き換え (`GI_GROUND_REPLACE`) | 1.0 | 0.0〜1.0 | 空の環境光に含まれる灰色の地面の照り返しを、GI が拾う実際の地面の色に置き換える割合 |

多重反射を上げると洞窟の入り口や室内の奥まで光が回り、重さはほとんど変わりません  
スクリーンスペースとボクセルでは 1 が物理的に正しい値です

空の光の遮蔽を 1 にすると、空が見える向きからだけ光が入り、軒下・洞窟の入り口・室内の奥が暗くなって入り口の向きが分かります  
ただ 1 では多重反射があっても暗すぎるので、既定は 0.5 にしてあります

日陰や室内が暗すぎるときは、まず GI の強さを上げます  
室内や洞窟の入り口だけが暗いなら、空の光の遮蔽を下げます  
照り返しの色が強すぎるときは 2 つの「色」を下げます  
草の緑が日陰や白樺の幹に乗るのが気になるとき (ビビッドで出やすい) は、こことルックの「照り返しの色の濃さ」を一緒に下げます

### ノイズと追従

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| GI のサンプル数 (`GI_SAMPLES`) | 2 | 1〜8 | 1 ピクセルのレイの数、増やすとノイズが減って重い |
| GI の解像度 (`GI_RES`) | 1/2 | フル / 1/2 | フルで細かくなるが重い |
| GI のノイズ除去 (`GI_DENOISE`) | 時間 + 空間 | なし / 時間 / 時間 + 空間 | 切るとまだらが残る |
| GI の履歴の長さ (`GI_HISTORY_MAX`) | 64 | 8〜128 | 平均する過去のフレーム数の上限、長いほど静かで短いほど反応が速い |
| GI の追従 (`GI_RESPONSE_STRENGTH`) | 1.0 | 0.5〜2.0 | 光が変わったときに履歴を縮める強さ、光源を置く・壊すときに早く追いつくがちらつきが少し増える |
| 新しく見えた所の GI のぼかし (`GI_SHORT_HISTORY`) | 8 フレーム | なし / 4 / 8 / 16 | 振り向いた直後など履歴の短い所を 2 倍の幅でぼかす |
| ボクセル GI のフェード幅 (`GI_VOXEL_FADE`) | 32 | 8〜64 | ボクセル範囲の端で外の空の光に溶かす幅 (ブロック) |
| GI の当たりの光源の光を使い回す (`GI_HIT_REUSE`) | OFF | ON / OFF | 光源の多い場所で軽くなる、照り返しの色が近くの光源の色にわずかに寄る |
| 画面外の GI の当たりの光源数 (`GI_HIT_LIGHTS`) | 全部 | 全部 / 8〜32 | 下げると光源の多い場所で軽くなり、画面外から照り返す光のノイズが少し増える |

使い回しと画面外の光源数は、スクリーンスペースとボクセルのときだけ効きます  
履歴の長さ・追従・新しく見えた所のぼかしは、ノイズ除去が「なし」だと効きません

重さを変えずにノイズを減らしたいなら、まず履歴の長さを上げます  
反応が遅くなるので、光源をよく置いたり壊したりするなら追従を少し上げます

ボクセル GI はボクセル範囲 (ブロックライトの画面) の外では普通の空の光に溶けます  
範囲が小さいと境目が見えやすいので、そのときはフェード幅を広げます  
大きくするほど、空から降りるときや遠景で境目が目立ちません

暗い洞窟に光が回り込まないときは、フォグの画面の「洞窟の光漏れ防止」が太陽の光を止めていることがあります ([sky-clouds-fog.md](sky-clouds-fog.md))
