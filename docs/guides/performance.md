# 重い設定と軽くする順番

## 軽くする順番

1. 品質プロファイルを 1 段下げる  
   「高」の次は「高 (軽量)」、その次は「高 (最軽量)」で、手法と見た目はそのまま、内部の解像度とサンプル数だけが下がります
2. パスごと止まる設定を切る (下の表)  
   切ったものはそのパスがまるごと実行されなくなるので、効きが大きいです
3. 解像度を下げる  
   光源トレース・GI・雲・ボリューメトリックライト・画面空間の光芒に、それぞれ解像度の設定があります
4. サンプル数を下げる  
   影・GI・光源・反射・ボリューメトリックライト・被写界深度に、それぞれあります
5. 上限を下げる  
   光源の数・ビンごとの光源の上限・ボクセル範囲です

たいていは 1 と 2 で足ります

## プロファイルごとの重さ

「高」を 1.0 としたときの重さです  
RTX 2080 Ti・1297x803 で 4 つの場面を測った平均で、設定 1 つずつの重さは測っていません

| プロファイル | 重さ |
|---|---|
| 低 | 測っていない |
| 中 | 0.55 |
| 高 (最軽量) | 0.83 |
| 高 (軽量) | 0.94 |
| 高 | 1.00 |
| 最高 | 0.99 |
| 極限 (軽量) | 1.02 |
| 極限 (バランス) | 1.57 |
| 極限 | 2.48 |

「高」「最高」「極限 (軽量)」の差は測るたびのばらつきと同じくらいで、「最高」が「高」より軽く出たのもそのせいです  
「極限」はボクセル GI を含めてすべてフル解像度で回すので、ほかより大きく重くなります

## パスごと止まる設定

| 設定 | 止まる値 | 止まるもの |
|---|---|---|
| 光源シャドウ (`LIGHT_SHADOWS`) | OFF | 光源のトレースとデノイズ (floodfill だけで照らす) |
| GI と AO (`GI_MODE`、`AO_MODE`) | 両方 OFF | GI / AO のパス |
| 雲 (`CLOUDS`) | 「体積雲 (3D)」より下 | 体積雲と雲の天気図のパス |
| 大気 (`ATMOSPHERE_MODE`) | 解析近似 | 大気 LUT のパス |
| 反射 (`REFLECTIONS`) | 空のみ | 反射のパス |
| ボリューメトリックライト (`VL`) | OFF | ボリューメトリックのパス |
| 画面空間の光芒 (`GODRAYS`) | OFF | 光芒の 3 パス |
| TAA (`TAA`) | OFF | TAA のパス |
| モーションブラーとシャッター (`MOTION_BLUR`、`SHUTTER`) | 両方 OFF | ぶれのパス |
| 被写界深度 (`DOF`) | OFF | ボケのパス |
| ブルーム・HDR モード・DR の補正 | すべて OFF | ブルームの縮小のパス |
| アナログ (`ANALOG`) | OFF | アナログの 2 パス |

ブルームの縮小は、ブルーム (`BLOOM`)・HDR モード (`LOCAL_TONEMAP`)・DR の補正 (`EXPOSURE_DR`) のどれかが ON なら走ります  
DR の補正は、露出がオート (平均・ヒストグラム) で、自動露出の動きが「現代」のときにだけ数に入ります

ネザーとエンドでは、空の LUT・雲・画面空間の光芒のパスは最初から止まっています

## 画面ごとの重い設定

### ブロックライト

- エンティティによる遮蔽 (`LIGHT_ENTITY_OCCLUSION`) は影パスでエンティティを描くので重く、プロファイル「低」では切ってあります
- 光の届く距離を「光の量」にすると光源ごとに照らす範囲が広がり、弱い光源の多い場面で重くなります  
  主要・弱い光源の距離と下限も、大きいほど重いです
- 1 ピクセルあたりの光源数 (`LIGHT_TRACE_COUNT`)・鏡面反射の光源数 (`LIGHT_SPECULAR_COUNT`)・接触影の光源数 (`LIGHT_CONTACT_SHADOW_COUNT`) は、上げた分だけ重くなります
- 光源の総数の上限 (`LIGHT_MAX_COUNT`) とビンごとの光源の上限 (`LIGHT_BIN_LIGHTS`) は、光源が密集した場所で効いてきます  
  ビンごとの上限は 64 より上で VRAM を約 10 MB 多く使います
- 光るブロックの面の光り方を「テクスチャのマスク」(`LIGHT_EMISSION_MASK_MODE`) にすると、光るブロックの近くで重くなります
- ボクセル範囲 (`VOXEL_VOLUME`) は大きいほど VRAM を使います

### 影と GI、マテリアル

- 影の解像度・影の距離・影のサンプル数は、上げるほど重くなります
- GI は「OFF」がいちばん軽く、「ボクセルレイトレース」がいちばん重い方式です
- 表面下散乱 (`SSS`) は、葉・草・雪・肌で影マップを読む回数が少し増えます

### 水と反射

- 水面のきらめき (`WATER_GLITTER`) は少し重いです
- 屈折の「ボクセルで辿る」と、反射の「SSR + ボクセル」は重い側の選択です
- 粗い反射のならし (`REFLECTION_FILTER_STRENGTH`) は「なし」で軽くなります

### 空・雲・フォグ

- 雲の品質・解像度・多重散乱のオクターブ数は、上げるほど重くなります  
  雲の描画距離は短いほど軽いです
- 積乱雲 (`CLOUD_CUMULONIMBUS`) は、嵐があるときだけ重くなります
- 雲の形を「バニラの形」にすると、晴れの日の雲の描画が Ray の形の約 1 割の重さになります  
  上の段を 2 段にすると約 0.5 ms 増えます
- 霧の層 (`FOG_LAYER`)・画面空間の光芒・遠くの光芒 (`VL_FAR`) は少し重いです

### カメラとレンズ

- 長時間露光 (`SHUTTER`) は画面の大きさに比例したメモリ (1080p で約 33 MB) を使い、少し重いです  
  「1 枚ずつ」はさらに半分を使います
- 点像の滲み (`LENS_POINT_SPREAD_STRENGTH`) は約 0.2 ms です
- レンズ効果の品質 (`LENS_QUALITY`) を上げるとゴーストの数と波長サンプル数が増えます
- 被写界深度の品質 (`DOF_QUALITY`) は 30 / 50 / 75 サンプルです
- アナログの効果は 1 画素あたり 1〜8 回の読みです ([analog.md](analog.md))
- DR の補正と HDR モードは軽いです
