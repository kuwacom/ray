# アナログ

「カメラ」>「アナログ」の `ANALOG` (既定 OFF) を ON にすると、2000 年代の家庭用 CCD ビデオカメラ (MiniDV・Digital8・HDV) で撮ったような画になります  
ON でパスが 2 つ増え、OFF ならアナログの処理はすべて止まります

効果は、撮像、ノイズ、画作り、記録の 4 つの画面に分かれていて、どれも `ANALOG` が ON のときだけ動きます

## 機材

`ANALOG_PRESET` (既定「標準の MiniDV」) で、スミアの強さなどビデオカメラの癖をまとめて選びます

| 機材 | 写り |
|---|---|
| カスタム | 効果ごとの `ANALOG_C_*` で自分で決める |
| 標準の MiniDV | 太陽の列に淡い筋 |
| 安いコンパクトのビデオ | 素子が小さく、筋がやや強い |
| 暗い所の自動ゲイン | 暗い場面のノイズが目立つ |
| 古い Digital8 | 太陽の列にはっきりした白い線 |
| HDV 1080i | 3CCD の HDV 機で、筋はほとんど見えない |
| PAL の MiniDV | 50 Hz 系の DV |

効果ごとの ON/OFF はどの機材でも効き、`ANALOG_C_*` の値は「カスタム」のときだけ変えられます

## 撮像

縦スミア (`ANALOG_SMEAR`、既定 ON) は、太陽を通る列に画面の上端から下端まで淡い筋を引きます  
筋の強さは列の平均の明るさで決まるので、空しか写っていない列はほとんど持ち上がりません  
たいまつなどの灯りは、重なった所や近くで大きく写った所にだけ筋が出ます  
灯りの筋だけを強めたいときは「灯りの筋の強さ」(`ANALOG_SMEAR_LIGHT_STRENGTH`、既定 1.0、0〜5) を上げます (太陽の筋は変わりません)

カスタムで筋を作るときの目安として、スミア比 (`ANALOG_C_SMEAR_RATIO`) は既定の 0.1 % で淡い筋、1.0 % ではっきりした白い線になります  
実物の家庭用の素子は 0.01 % ほどですが、ゲームの太陽は実物ほど明るくないので大きめにしてあります

ブルーミング (`ANALOG_BLOOMING`、既定 ON) は、飽和した画素から電荷があふれて、明るい灯りや太陽の上下が白くつぶれる現象です  
スミアと違って、白く飛ぶのは光源の近くだけです  
機材の値が 0 だと見えないので、安いコンパクト・古い Digital8 を選ぶか、カスタムで上げます  
1 画素あたり 8 回読むので少し重めです

解像 (`ANALOG_RESOLUTION`、既定 ON) は、細かさを記録形式の画素数 (DV は横 720) と走査線まで落とします  
明るさにだけ掛かり、1 画素あたり 8 回読みます

## ノイズ

「センサーのノイズ」(`ANALOG_NOISE`、既定 ON) が下の 5 種をまとめて切り替えます  
「ノイズの強さ」(`ANALOG_NOISE_STRENGTH`、既定 1.0、0〜3) は 5 種すべてに掛かり、0 にすると処理の重さもなくなります  
これが ON の間は、ポストプロセスのフィルムグレインは掛かりません

暗い場面ほど自動ゲインが上がってノイズが増えます  
露出をカメラ (M・P・A・S) にしているときは ISO がゲインになり (ゲイン = ISO / 100)、ISO を上げるほど増えていきます

| ノイズ | 見え方 |
|---|---|
| ショットノイズ (`ANALOG_SHOT_NOISE`) | 中間調から明部の細かい粒 |
| 暗部ノイズ (`ANALOG_DARK_NOISE`) | 暗い場面の暗い所のざらつき |
| 色ノイズ (`ANALOG_CHROMA_NOISE`) | 暗部に乗る色の斑点、4:1:1 の記録では横長 |
| 固定パターンノイズ (`ANALOG_FPN`) | 画素ごとのむらと列ごとの縦縞、画面に張り付いて動かない |
| ホットピクセル (`ANALOG_HOT_PIXELS`) | 暗い場面で白く光る点、画面に張り付いて動かない |

固定パターンノイズとホットピクセルは、機材が「暗い所の自動ゲイン」「安いコンパクトのビデオ」「古い Digital8」のときか、カスタムで値を上げたときにだけ見えます

カスタムでは自動ゲインの上限 (`ANALOG_C_AGC_MAX`、既定 2 段) と、自動ゲインの始まり (`ANALOG_C_AGC_EV`、既定 -1) も決められます  
画面の露出 (適用 EV) が始まりの値より暗いと感度が上がり始めます  
晴天は 0 前後、洞窟は -1、夜の村は -2.5 くらいです

## 画作り

ニーと白飛び (`ANALOG_KNEE`、既定 ON) は、ビデオカメラのニーで明部をなだらかに寝かせて、記録の上限で切ります  
色ごとに切れるので、明るい色は白へ抜けます  
ON の間はトーンマップ (と溶岩の見え方の調整) の代わりにこれが掛かり、ポストプロセスのトーンマップの選択は使われません

輪郭強調 (`ANALOG_SHARPEN`、既定 ON) は、縁の明るい側を白く、暗い側を黒く縁取ります (ハロー)  
明るさにだけ掛かり、細かい揺らぎは強調しません  
1 画素あたり 1 回の読みで軽いです

## 記録

テープに記録する形式で起きる崩れです  
記録形式 (`ANALOG_C_FORMAT_MODE`) は NTSC DV (720x480、色差は横 1/4 の 4:1:1)、PAL DV (720x576、4:2:0)、HDV 1080i (1440x1080、4:2:0) から選びます

| 効果 | 見え方 | 1 画素あたりの読み |
|---|---|---|
| 色のにじみ (`ANALOG_CHROMA`) | 色だけ粗く記録するので、赤や青の縁が横 (4:2:0 は縦にも) ににじむ、明るさの細かさはそのまま | 6〜8 回と画面のミップの作成 |
| ブロックノイズ (`ANALOG_BLOCK`) | DV の圧縮の 8x8 のブロックの段差、細部とノイズが消える、視点を動かすとさらに消える | 4 回 (モスキートと共有) |
| モスキートノイズ (`ANALOG_MOSQUITO`) | 縁の周りにちらつく細かい斑点、平らな所には出ない | 同上 |
| ドロップアウト (`ANALOG_DROPOUT`) | テープの傷で、散らばったブロックが一瞬 (約 1/15 秒) 前のフレームの像になる、視点が動いているときだけ | 1 回 |
| インターレース (`ANALOG_INTERLACE`) | 偶数と奇数の走査線を 1/60 秒ずらして撮るので、視点を動かすと動いた所が櫛のようにずれる | 2 回 |

ドロップアウトの頻度は機材で決まり、標準と PAL の MiniDV は 1 分に 1 回ほど、古い Digital8 は 20 回ほどで、ほかの機材では起きません  
インターレースの櫛は視点の動きでしか出ず、視点が止まっていればモブや水が動いても出ません

「インターレースの見せ方」(`ANALOG_INTERLACE_MODE`、既定「織り込み」) は機材によらず効きます  
織り込みはパソコンで見た DV のように 2 つの走査線を 1 枚に並べ、動くと櫛になります  
フィールド表示はテレビのように 1/60 秒ごとに片方の走査線だけを出すので、細かい横縞がちらつきます

「色の戻し方」(`ANALOG_C_CHROMA_UPSAMPLE_MODE`) は、補間なら色がなめらかににじみ、最近傍なら色の境目が階段状になります

## ほかの設定との関係

- 露出の動きを「VHS」か「DV」にすると、ゲインに合わせてノイズが増えます ([camera.md](camera.md))
- 重いときは読みの多い「解像」「ブルーミング」「色のにじみ」から切ります
- 古い Iris (1.7) と Oculus では、アナログの見え方をゲームの中でまだ確かめていません
