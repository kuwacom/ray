# ポストプロセス

## トーンマップ

`TONEMAP` (既定 AgX) は、明るさの幅の広い絵を画面に出せる範囲に収める変換です  
AgX は彩度が控えめ、AgX (パンチ) はコントラストが強めで少し鮮やか、AgX (ゴールデン) は暖色寄りです  
ほかに ACES、Reinhard-Jodie、PBR Neutral を選べます  
トーンマップが違うと色も明るさも変わるので、ルックを見比べるときはそろえます  
アナログの「ニーと白飛び」が ON の間は、ここで何を選んでも使われません ([analog.md](analog.md))

### HDR モード

`LOCAL_TONEMAP` (既定 OFF、0.05〜1.00 の 20 段階) は、スマホの HDR 撮影のような局所トーンマップです  
たいまつの照らす壁・溶岩・空のような明るい所を下げ、その周りの暗い所を上げるので、夜の景色で明るい所と暗い所の両方が見えます

値は場所ごとの明るさの差を縮める割合で、上げるほど平たくなります  
暗い所は最大 2 EV 上げ、明るい所は最大 3 EV 下げます  
画面全体の明るさは自動露出のままで、明るい所と暗い所の境目はぼかしません

処理は軽いですが、ブルームを切っていてもブルームの縮小は走ります  
OFF にすれば処理が丸ごと外れます  
似た効果の「DR の補正」はカメラの画面にあります ([camera.md](camera.md))

## 色

「ポストプロセス」>「色」

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| 彩度 (`SATURATION`) | 1.0 | 0.0〜2.0 | ルックの値に掛かる |
| コントラスト (`CONTRAST`) | 1.0 | 0.5〜2.0 | ルックの値に掛かる |
| ホワイトバランス (`WHITE_BALANCE`) | 6500 K | 2500〜12000 K | 想定する照明の色温度、低いほど暖色を打ち消して画面が青くなる |
| プルキンエ効果 (`PURKINJE_STRENGTH`) | 0.3 | 0.0〜1.0 | 暗い所で色が抜けて青緑寄りに見える目の特性 |

### カラーグレーディング

`GRADING` (既定 ON) は、DaVinci Resolve のカラーページのような調整の画面です  
既定値ではどれも何もせず、ルックのプリセットの上に重なります (彩度は掛け算、色や明るさのずれは足し算)

| 画面 | 調整できるもの | 掛かる所 |
|---|---|---|
| 基本 | 色温度・ティント・コントラストとピボット・彩度とバイブランス・RGB のオフセット・ハイライトの圧縮・シャドーの持ち上げ | トーンマップ前 |
| シャドー・ミッド・ハイライト | 明るさの範囲ごとの色・輝度・彩度・コントラスト、範囲の境目と柔らかさ | トーンマップ前 |
| 色相ごと | 赤・橙・黄・緑・水色・青・紫・マゼンタの色相・彩度・明るさ | トーンマップ前 |
| リフト・ガンマ・ゲイン | 赤・緑・青・輝度ごとのカラーホイール | トーンマップ後 |
| トーンカーブ | 0・10・25・50・75・90・100% の 7 点を通る単調な曲線、RGB か輝度に掛ける | トーンマップ後 |
| スプリットトーン | シャドーとハイライトに別の色を足す、明るさは変わらない | トーンマップ後 |
| CDL | ASC CDL (スロープ・オフセット・パワー・彩度) | LUT の後 |

掛かる順は ホワイトバランス -> ティント -> オフセット -> コントラスト -> シャドー・ミッド・ハイライト -> ハイライトの圧縮・シャドーの持ち上げ -> 彩度・バイブランス -> 色相ごと -> トーンマップ -> リフト・ガンマ・ゲイン -> トーンカーブ -> スプリットトーン -> LUT -> CDL です

トーンマップ前の調整は露出の段 (EV) の上で効くので、昼・夜・洞窟で明るさが変わっても同じ段数だけ動きます  
はみ出した分はトーンマップが畳むので、色がクリップしにくいです  
トーンマップ後の調整は、黒 0・白 1 の表示の値に掛かります

空の青を濃くしたいときは、色相ごとの「青の明るさ」を下げます  
「グレーディング」を切ると、この画面の調整とルックのプリセットのグレーディングが外れ、ホワイトバランス・コントラスト・彩度・LUT・CDL は残ります  
最後のパスで計算するだけなので、重さはほとんど変わりません

カスタムルックの 9 つの設定もこの画面の下にあります ([profiles.md](profiles.md))

### 色が強すぎるとき

色はルック、グレーディング、LUT、CDL の順に重なります  
どこで色が変わったか分からなくなったら、「グレーディング」を切ってルックだけの色に戻して比べます  
ブリーチバイパスやクロスプロセスのような強いルックに、Velvia 風のような強い LUT を重ねると、色もコントラストも強くなりすぎます

## 効果

「ポストプロセス」>「効果」

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| ブルーム (`BLOOM`) | ON | ON / OFF | 光のにじみ、プロファイル「低」では OFF |
| ブルームの強さ (`BLOOM_STRENGTH`) | 0.5 | 0.0〜4.0 | ルックの値に掛かる |
| ブルーミーフォグ (`BLOOM_FOG`) | 0.15 | 0.0〜2.0 | 遠景の広いにじみ、ルックの値に掛かる |
| フィルムグレイン (`FILM_GRAIN`) | 0.008 | 0.0〜0.1 | アナログの「センサーのノイズ」が ON の間は掛からない |
| ブロック選択枠 (`SELECTION_OUTLINE`) | ON | ON / OFF | 見ているブロックの枠線 |
| にじみ全体の強さ (`LENS_GLOW_STRENGTH`) | 1.0 | 0.0〜3.0 | ブルームとレンズのにじみをまとめて強弱する ([lens.md](lens.md)) |

夜は月や光源のにじみを出すため、ブルームをさらに 3 倍にして混ぜます  
ブルームを切ると、ブルームを使うレンズの効果 (明るい画素のフレア・ハレーション・球面収差の滲み) も出なくなります

## アンチエイリアスとシャープネス

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| TAA (`TAA`) | ON | ON / OFF | 時間方向のアンチエイリアス、切るとパスごと止まる |
| シャープネス (`CAS_STRENGTH`) | 0.5 | 0.0〜1.0 | CAS による輪郭の補正 |

TAA を切ると、魚眼の「歪曲を TAA で組み立てる」のようにジッターを使う処理も使えなくなります  
水と反射の画面の「反射光のきらめき」を OFF にすると、TAA で細かい照り返しが弱まります
