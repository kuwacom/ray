# 空・雲・フォグ

ネザーとエンドには空の LUT・雲・画面空間の光芒がなく、そのパスは最初から止まっています

## 空

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| 大気 (`ATMOSPHERE_MODE`) | 物理 (LUT) | 解析近似 / 物理 (LUT) | 空と大気を LUT で描くか、軽い近似で描くか |
| 太陽の明るさ (`SUN_BRIGHTNESS`) | 1.0 | 0.25〜4.0 | |
| 月の明るさ (`MOON_BRIGHTNESS`) | 1.0 | 0.25〜6.0 | |
| 空の明るさ (`SKY_BRIGHTNESS`) | 1.0 | 0.25〜4.0 | |
| 空の環境光の彩度 (`SKY_AMBIENT_SATURATION`) | 0.5 | 0.2〜1.0 | 日陰を照らす空の光の色の濃さ、ルックの値に掛かる |
| 太陽と月 (`SUN_MOON_STYLE`) | 丸 | バニラ / 丸 / リアルの月 | 太陽と月の描き方 |
| 星 (`STARS`) | ON | ON / OFF | |
| 薄明の長さ (`TWILIGHT_STRETCH`) | 1.0 | 1.0〜3.0 | 日の出前と日没後の空の色を長く見せる |

大気を「解析近似」にすると大気 LUT のパスが止まって軽くなり、空の色の見え方が変わります  
プロファイル「低」と「中」は近似です

空の環境光の彩度を上げると日陰が青みを帯び、日向の暖色との差が出ます  
1 で空の色そのままになり、日陰の雪がかなり青くなります

太陽と月の「バニラ」はゲームのテクスチャ、「丸」は丸い太陽と満ち欠けだけ付けた一様な月、「リアルの月」は満ち欠けごとの NASA の写真で月を描きます  
月の明るさ・水面の照り返し・フレア・雲の影は「丸」と「リアルの月」で同じです

Minecraft の市民薄明は 20 秒ほどしかないので、薄明の長さで空の色だけを引き延ばせます  
太陽の円盤・日光・影の動きは変わりません

## 雲

`CLOUDS` (既定「体積雲 (3D)」)

| 値 | 雲 |
|---|---|
| OFF | 描かない |
| バニラ | ゲーム本来の雲 (fancy) |
| 体積雲 (2D) | Ray の軽い 2D の雲、雲の影も付く |
| 体積雲 (3D) | 3 層の体積雲、天気図で雲の種類と量が決まる |

体積雲 (3D) では、低層 (積雲・層積雲・乱層雲・積乱雲) と中層 (高積雲・高層雲) を体積で、上層 (巻雲・巻積雲・巻層雲) を平面で描きます  
「体積雲 (3D)」より下にすると体積雲のパスが止まるので、重いときにいちばん効く設定です

| 設定 | 既定 | 補足 |
|---|---|---|
| 雲の品質 (`CLOUD_QUALITY`) | 中 | 低 / 中 / 高 / 最高、レイマーチの歩数 |
| 雲の解像度 (`CLOUD_RES`) | 1/2 | フル / 1/2 / 1/4 |
| 時間アップスケール (`CLOUD_TEMPORAL`) | ON | チェッカーボードで描いて前のフレームで埋める |
| 多重散乱のオクターブ数 (`CLOUD_MULTISCATTER`) | 4 | 2 / 4 / 8、多いほど重い |
| 雲の描画距離 (`CLOUD_DRAW_DISTANCE`) | 80 | 20〜160、低層と中層を描く距離 (現実の寸法の km)、短いほど軽い |

品質を変えても形と陰影は同じで、上げるとノイズが減って重くなります  
オクターブ数が少ないときは残りを最後の段にまとめるので、明るさはほぼ変わりません

### 雲の形

`CLOUD_STYLE` (既定「Ray」) で、低層の雲の形・濃さ・光の当たり方と、晴れた日の各層の雲量をまとめて選びます  
下の量や大きさの設定は、選んだスタイルの値に掛かります

| スタイル | 見た目 |
|---|---|
| カスタム | 「カスタムの雲の形」の画面で決める |
| Ray | こぶの重なる積雲と、塊の間の青空 |
| Bliss 風 | 小さめの塊がまばらで、縁がほつれ、陰が深い |
| バニラの形 | バニラの雲と同じ高さ・模様・流れで、格子を 2 倍 (24 ブロック) にした厚さの一様な板雲、角は少し丸い |
| 現実に忠実 | 積雲の実測に近い濃さで輪郭がくっきり |
| 綿あめ | 縁のもやが広い、柔らかい丸い雲 |
| 入道雲 | 背の高い白い積雲が間を空けて立つ |
| まばらな晴天積雲 | 小さな扁平雲が広い青空に散らばる |
| 層積雲の曇り | 平たい塊が空の大半を覆う |

雨と雷雨の雲は、バニラの形のほかはどのスタイルでもほぼ同じです

「バニラの形」は中層・上層・巻雲・積乱雲を描かず、雲量・大きさ・風・高さテンプレートも効きません  
そのぶん軽く、晴れの日の雲の描画は Ray の約 1 割の重さです  
専用の「バニラの形の雲」の画面で、厚さ (`CLOUD_VANILLA_THICKNESS`、既定 16、4〜24)、上の段 (`CLOUD_VANILLA_TIER_COUNT`、既定「中段と上段」)、上の段の雲量 (`CLOUD_VANILLA_TIER_COVERAGE`、既定 0.35)、上の段の高さ (`CLOUD_VANILLA_TIER_HEIGHT`、既定「高い」) を決めます  
上の段を 2 段にすると約 0.5 ms 増えます

「カスタムの雲の形」の画面 (`CLOUD_S_*`) では、形 (積雲 / バニラの形)、背丈、対流の強さ、雲種のずらし、雲の間隔、こぶの段、雲底のちぎれ、こぶの陰、日向の明るさを決めます  
範囲は [../settings.md](../settings.md) にあります

### 量・大きさ・高さ・天気

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| 雲量 (`CLOUD_COVERAGE`) | 1.1 | 0.0〜3.0 | 全層の雲の量の倍率、実際の量は日ごとの天気・時刻・雨でも変わる |
| 雲の大きさ (`CLOUD_SCALE`) | 3.0 | 0.5〜6.0 | 水平の大きさの倍率 |
| 雲の速さ (`CLOUD_SPEED`) | 1.0 | 0.0〜5.0 | |
| 雲の高さテンプレート (`CLOUD_HEIGHT_PRESET`) | バニラ | バニラ / 高さ拡張 / 現実比 / カスタム | 現実の雲の高さをワールドにどう写すか |
| 雲の気候 (`CLOUD_REGION_PRESET`) | 温帯 | 温帯 / 熱帯 / 乾燥 / 寒冷・極域 / 海洋 / カスタム | 出る雲の種類と頻度、日替わりの傾向 |
| 雲の影 (`CLOUD_SHADOWS`) | ON | ON / OFF | |
| 雲の中の視程 (`CLOUD_INTERIOR_VISIBILITY`) | 64 | 0〜96 | 雲の中の見通し (ブロック)。既定で雲の中も外から見た雲と同じ濃さ、小さいほど雲の中が濃い。雲の濃さ (低層の濃さ) にも比例する。0 で雲の中の効果なし (画面の外の太陽・月の雲による隠れも) |

高さテンプレート

- バニラ (-64 -> 320): 積雲の雲底が y 165、積乱雲の頂と巻雲が y 280〜300
- 高さ拡張: 雲底が y 525、頂が y 1800 前後
- 現実比: 1 ブロック 1 m (雲底 1500、巻雲 8〜10 km)
- カスタム: 各層の高度と厚さのスライダーで決めます  
  上の層ほど強く縮めるので、低い積雲は自然な形のままです

気候

- 温帯: 積雲と巻雲、湿った日は層積雲
- 熱帯: 午後の雄大雲と遠くの積乱雲
- 乾燥: 小さな雲がまばら
- 寒冷・極域: 低い層状の雲と氷晶の雲
- 海洋: 広い層積雲とふわふわの積雲
- カスタム: 各層の画面の「気候」のスライダー (`CLOUD_C_*`)

### 層ごとの画面

「低層の雲」「中層の雲」「上層の雲」「積乱雲」には、量・濃さ・大きさ・浸食・風速と風向のスライダーが層ごとにあります  
浸食は縁を削る強さで、小さいとなめらかな綿、大きいとカリフラワーのようになります  
風向は 0 が東 (+X)、90 が南 (+Z) です  
高度と厚さは高さテンプレートが「カスタム」のときだけ効き、中層・上層・積乱雲では 0 が自動です

- 薄い断片雲 (`CLOUD_FRACTUS`、低層): 濃い雲の周りに散る、薄くちぎれた雲
- 上層雲 (`CLOUD_CIRRUS`、既定 ON): 上空 9 km あたりの半透明の氷晶の雲
- 積乱雲 (`CLOUD_CUMULONIMBUS`、既定 ON): かなとこ・乳房雲・降水の柱のある雷雨の塔、嵐のときだけ重くなる

「雲の詳細」の画面は形を変えずに光の当たり方を変えます  
縁の柔らかさ・縁のもや・芯の濃さ・銀の縁・縁の暗さ・雲の中の空の光・雲底の暗さがあります

## フォグ

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| フォグの濃さ (`FOG_DENSITY`) | 1.0 | 0.0〜8.0 | ルックの値に掛かる、変えても読み込み直しが速い |
| フォグのスタイル (`FOG_STYLE`) | Ray (物理) | Ray / Bliss 風 / Nostalgia 風 / カスタム | もやと霧の出方 |
| フォグの高さテンプレート (`FOG_HEIGHT_PRESET`) | 雲に合わせる | バニラ / 高さ拡張 / 実寸 / カスタム / 雲に合わせる | もや・霧の層・地表の霧の高さ |
| バイオームのフォグ (`FOG_BIOME`) | ON | ON / OFF | バイオームで霧を変える |
| 描画距離端のフォグ (`BORDER_FOG`) | ON | ON / OFF | |
| ネザーのフォグの濃さ / エンドのフォグの濃さ | 1.0 / 1.0 | 0.0〜4.0 | |

バイオームのフォグが ON だと、湿地とジャングルは霧が多く、砂漠と荒地は砂塵のもやだけ、雪のバイオームはもやが薄く、海は谷霧が少なくなります

どのスタイルでも、遠くの空気は同じ方角の地平線の空の色に溶けます  
全体の濃さはフォグの濃さとルックで決まります

- Ray: 物理ベースで、上面の平らなもやの層、朝の霧の土手と谷霧
- Bliss 風: 濃いめのもやと遠景の霞み、霧の土手が多い  
  夕方と夜にも地表の霧が出て、太陽側の霧が強く光ります
- Nostalgia 風: 霧の土手なし  
  もやは上へなだらかに薄れ、遠景の霞みは軽く、地表の霧は朝と雨のときだけ
- カスタム: 「フォグのスタイル (カスタム)」のスライダー (`FOG_C_*`) で、もや・遠景の霞み・霧の層・地表の霧・日の当たる霧の輝きを決めます

高さテンプレート

- バニラ: 昼のもやは y 143 まで、霧の層は y 70〜105、地表の霧は y 71 まで
- 高さ拡張: もやは y 406 まで、霧の層は y 90〜200
- 実寸: 1 ブロック 1 m (もや 1.1 km、霧の層 100〜440 m)
- カスタム: 「フォグの高さ」の画面のスライダー
- 雲に合わせる: 雲の高さテンプレートに従います (もやの上端は雲底の 3/4)

### 霧の層と地表の霧

| 設定 | 既定 | 変わるもの |
|---|---|---|
| 霧の層 (`FOG_LAYER`) | ON | 中くらいの高さ (バニラで y 70〜105) に浮かぶ上面の平らな霧の塊、少し重い |
| 地表の霧 (`FOG_MIST`) | ON | 夜に谷や水面の上に溜まる放射霧 |
| 霧の高度 (`FOG_MIST_ALTITUDE`) | 72 | 地表の霧の上端、テンプレートがカスタムのときだけ |

霧の層は朝と湿った日に多く、雨では広く覆い、光芒がいちばんよく見えるのもこの中です  
地表の霧は明け方にいちばん濃く、日の出から 2 時間ほどで消えます  
晴れて湿った日と雨の後に濃く出ます

### ボリューメトリックライト

`VL` (既定 ON) は、太陽や月の光が霧やもやの中を通って見える光芒です  
影マップを使うので、影の距離の内側できれいに出ます

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| ボリューメトリックのサンプル数 (`VL_SAMPLES`) | 8 | 4〜32 | 少ないとノイズが出る |
| ボリューメトリックの解像度 (`VL_RES`) | 1/2 | フル / 1/2 / 1/4 | |
| 光芒の強さ (`VL_STRENGTH`) | 1.0 | 0.0〜4.0 | |
| 色付きの光芒 (`VL_COLORED_SHADOWS`) | OFF | ON / OFF | 色ガラスを通った光芒に色が付く、プロファイル「最高」から ON |
| 雲影の光芒 (`FOG_CLOUD_SHADOWS`) | ON | ON / OFF | 雲の影を光芒に落とす |
| 遠くの光芒 (`VL_FAR`) | ON | ON / OFF | 影の距離より遠くの光芒を、丘・木・建物から画面上でたどって出す、少し重い |
| ブロックライトのフォグ (`FOG_BLOCKLIGHT`) / 強さ (`FOG_BLOCKLIGHT_STRENGTH`) | ON / 0.5 | 0.0〜4.0 | たいまつなどの光がフォグを照らす |
| 洞窟の光漏れ防止 (`CAVE_LEAK_PREVENTION`) | ON | ON / OFF | 空の光が届かない所に太陽の光と光芒を入れない |

遠くの光芒は、描画距離が影の距離より長いときだけ効きます

洞窟の光漏れ防止は、影マップに抜けがあっても洞窟に日が差さないようにし、洞窟の遠くのもやも抑えます  
その代わり、横穴の奥や深い海の底が暗くなることがあるので、気になるときは OFF にします  
ボリューメトリックライトを OFF にするとそのパスが止まりますが、画面空間の光芒は別のパスなので残ります

### 画面空間の光芒

`GODRAYS` (既定 ON) は、太陽や月の周りの空から木・山・建物の隙間を通る光の筋を、画面上で放射状に伸ばします  
霧が濃いほど強く出て、少し重めです

| 設定 | 既定 | 範囲 |
|---|---|---|
| 強さ (`GODRAYS_STRENGTH`) | 1.5 | 0.0〜8.0 |
| 解像度 (`GODRAYS_RES`) | 1/2 | 1/2 / 1/4 |
| サンプル数 (`GODRAYS_SAMPLES`) | 8 | 6〜16 |

強さ 1.0 は控えめで筋が淡く見えます  
サンプル数は多いほど滑らかで、少ないと細かいノイズが出ます
