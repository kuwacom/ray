# レンズ

「カメラ」>「レンズ」の `LENS_PRESET` (既定「現代の単焦点 (控えめ)」) で、実在のレンズの写りを選びます  
フレアのゴーストの色と形、光条の本数、ボケの形、にじみ、周辺の暗さ、歪曲がレンズごとに変わります

## レンズの選び方

| 写り | レンズ | 合う FOV |
|---|---|---|
| 癖の少ない標準 | 現代の単焦点、Canon FD 50/1.4 S.S.C. | 30 |
| 開放のにじみ・ぐるぐるボケ | Helios 44-2、Super Takumar 50/1.4、Petzval | 30 |
| 高コントラストでゴーストが少ない | Zeiss Sonnar 50/1.5 | 30 |
| 柔らかく四隅が落ちる | Leica Summilux 35/1.4、Canon 50/1.2、Canon 50/0.95 | 32 / 30 / 30 |
| 超広角 | Hologon 15/8、Flektogon 20/4、Ultra Wide-Heliar 12/5.6、New FD 14/2.8L | 68 / 54 / 80 / 72 |
| 魚眼 | Rokkor 16/2.8、ぎょぎょっと 20/8 | 110 / 107 |
| ソフトフォーカス | FA 28/2.8 Soft | 40 |
| ボケの縁が溶ける | STF 135/2.8 | 30 |
| 横のストリークと縦長のボケ | アナモルフィック | どれでも |

それぞれの構成・年代・描写は README の「レンズ」の表にあります

合う FOV は、35mm 判の横幅 36mm を画面の横幅に合わせたときの実物の画角を、Minecraft の FOV (縦の画角) に直した値です  
縦の FOV = 2 atan(18 / f × 9 / 16) で、35mm なら 32、20mm なら 54、15mm なら 68 になります  
50mm より長いレンズはゲームの FOV の下限 (30) より狭いので 30 にしてあり、ほかの FOV で使っても写りの味付けとして掛かります

収差の強さは画面の隅を 35mm 判の隅に合わせてあるので、FOV を変えても形は同じに見えます  
魚眼の写り方だけは角度で計算するので、FOV で変わります

## フレアと光条

「レンズフレア」(`LENS_FLARE`、既定 ON) が太陽と月のフレアの元スイッチで、細かい効果はそれぞれ切れます  
太陽や月が画面の近くにあるときに目立つので、撮影のとき以外で邪魔なら元スイッチを切ります

| 設定 (内部名) | 既定 | 写り |
|---|---|---|
| フレア全体の倍率 (`LENS_FLARE_STRENGTH`) | 1.0 | 0.0〜10.0、1 でプリセットどおり |
| ゴースト (`LENS_GHOSTS`) | ON | レンズ面の内面反射の像、光源が端に寄るほど欠けた形になる |
| 明るい画素のフレア (`LENS_SCREEN_FLARE`) | ON | たいまつや溶岩などの明るい画素からもゴーストと横のストリークを出す、ブルームが要る |
| 光条 (`LENS_STARBURST`) | ON | 絞り羽根の回折、偶数枚は枚数と同じ本数、奇数枚は 2 倍、絞るほど長い |
| ハロー (`LENS_HALO`) | OFF | 画面の中心を囲む虹色のリング |
| レンズの汚れ (`LENS_DIRT`) | ON | 前玉のほこりや指紋が、明るい光の近くで浮かぶ |

ゴーストは絞りの形・コーティングの色・波長ごとのずれから計算していて、明るさは反射率から求めた値です

「レンズ効果の品質」(`LENS_QUALITY`、既定「高」) で、ゴーストの数 (8 / 12 / 16 / 24) と、色収差とゴーストの波長サンプル数 (3 / 4 / 5 / 7) が決まります  
上げるほど重く、プロファイル「低」は最低、「極限」は最高です  
「低」でもレンズフレアは ON なので、重いときはまずこの品質を下げます

## にじみ

| 設定 (内部名) | 既定 | 写り |
|---|---|---|
| にじみ全体の強さ (`LENS_GLOW_STRENGTH`) | 1.0 | 0.0〜3.0、明るい物の周りに光が広がる効果をまとめて強弱する |
| ベーリンググレア (`LENS_VEILING_GLARE`) | ON | レンズ内の散乱で画面全体が薄く霞み、逆光でコントラストが下がる |
| ハレーション (`LENS_HALATION`) | ON | 強い光の周りの赤いにじみ (フィルムの効果)、ブルームが要る |
| 点像の滲みの強さ (`LENS_POINT_SPREAD_STRENGTH`) | 1.5 | 白を超えた鏡面の点 (水面・金属・ガラスに映った太陽) に掛ける、0 で無効 |
| 点像の滲みの大きさ (`LENS_POINT_SPREAD_SIZE`) | 大 | 小 (約 1〜2 px) / 中 (3〜5 px) / 大 (4〜8 px) / 特大 (7〜10 px) |
| 球面収差の滲み (`LENS_SOFT_FOCUS`) | ON | 開放でハイライトが柔らかくにじむオールドレンズの描写、ブルームが要る |

にじみ全体の強さは、ブルーム・ブルーミーフォグ・点像の滲み・フレア類・ベーリンググレア・球面収差の滲み・ハレーション・玉ボケの縁の明るさに、それぞれの強さの上から掛かります  
0 にするとこれらがすべて消えます  
光がにじみすぎると感じたら、個別に切るよりこれを下げるほうがバランスが崩れません

点像の滲みは光の総量を変えず、明るい点ほど大きく見せます  
大きくするほど隣のきらめきとつながって、もやがかかったように見えます  
「反射光のきらめき」が ON のときだけ効き、約 0.2 ms 掛かります

## 歪みと周辺

| 設定 (内部名) | 既定 | 写り |
|---|---|---|
| 歪曲収差 (`LENS_DISTORTION`) | ON | 直線が樽型・糸巻き型・陣笠型に曲がる、魚眼の写り方も含む、OFF でゲームの直線写像のまま |
| 歪曲収差の強さ (`LENS_DISTORTION_SCALE`) | 1.0 | 0.0〜4.0、1 でレンズの処方どおり、上げると誇張する (魚眼の写り方は変わらない) |
| 魚眼の合わせ方 (`LENS_FISHEYE_FIT`) | 隅まで埋める | 隅まで埋める / 横幅を合わせる |
| 歪曲を TAA で組み立てる (`LENS_WARP_IN_TAA`) | 自動 | 自動 / final (引き伸ばし) / TAA |
| 倍率色収差 (`LENS_CHROMATIC`) | ON | 画面の端ほど縁が虹色にずれる |
| 軸上色収差 (`LENS_AXIAL_CA`) | ON | 前ボケの縁が紫、後ボケの縁が緑、被写界深度が要る |
| ぐるぐるボケ (`LENS_SWIRL`) | ON | 周辺の背景が渦を巻く、被写界深度が要る |
| 口径食 (`LENS_OPTICAL_VIGNETTING`) | ON | 周辺の減光と、端のボケがレモン形に欠ける猫目ボケ |
| ビネット (`VIGNETTE`) | 0.3 | 0.0〜2.0 |

Flektogon の陣笠型は処方どおりだと 2% ほどの控えめな曲がりです

### 魚眼

魚眼の FOV は上限の 110 にしてあります  
実物の対角 180° はゲームが描ける範囲 (FOV 110 で対角 142°) を超えるためです

「隅まで埋める」は黒い部分が出ない代わりに画角が少し狭くなります  
「横幅を合わせる」は横の画角が 137° になって実物 (140°) に近づきますが、描画の範囲の外になる四隅が黒くなります  
ぎょぎょっと (Nikon 20mm F8) は、「隅まで埋める」なら FOV 107 で実物の 20mm になります

魚眼は中心を 2 倍ほど引き伸ばすので、少し柔らかく写ります  
「歪曲を TAA で組み立てる」を TAA にすると、ジッターで毎フレームずれた画面から出力を組み立てるので、止まっているときやゆっくり動くときは中央も細かく写ります  
速く動くときと TAA を切っているときは final と同じ写りです  
「自動」は魚眼と強い歪曲のときだけ TAA を使います  
どちらも TAA が ON である必要があります ([post-processing.md](post-processing.md))

## カスタムレンズ

レンズを「カスタム」にしたときだけ、右上の「カスタムレンズ」の画面 (`LENS_C_*`) が効きます  
ON/OFF のスイッチはどのレンズでも効きますが、強さの値はカスタムのときだけ変えられます

- レンズ構成 (`LENS_C_DESIGN`): ゴーストの並びを決める設計で、15 種から選びます
- コーティング (`LENS_C_COATING`): マルチは淡い緑と紫のゴースト、単層は琥珀とマゼンタで濃く、無しはかなり強く出ます
- 開放 F 値 (`LENS_C_F_OPEN`)、絞り羽根の枚数 (`DOF_APERTURE_BLADES`) と丸み (`LENS_C_BLADE_ROUNDNESS`)
- 効果ごとの強さ: ゴースト・明るい画素のゴースト・光条とその長さ・ハロー・横のストリーク・汚れとそのコントラスト・ベーリンググレア
- 歪み: 歪曲 (正で樽型、負で糸巻き型)、4 次の項 (歪曲と逆の符号で陣笠型)、写像 (直線 / 魚眼)、魚眼の写像 (`LENS_C_FISHEYE_K`)、倍率色収差、軸上色収差
- ボケの形: ぐるぐるボケ、像面湾曲、口径食、アナモルフィックの圧縮率、ボケの縁の明るさ (正でバブルボケ、負で柔らかいボケ)、アポダイゼーション (1.96 で Minolta STF 135 相当)
- 黄変 (トリウムガラス)、ハレーション、球面収差の滲み

それぞれの範囲は [../settings.md](../settings.md) にあります

## 絞りとにじみ

FA 28 Soft と Canon 50/0.95 のにじみは開放でいちばん強くなります  
F 値を変えたいときは、カメラの「絞りの決め方」を「F 値を指定」にします ([camera.md](camera.md))  
「ボケの量」のままだと、FA 28 Soft は開放の F2.8 で写ります
