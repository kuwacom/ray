# ブロックライト

たいまつ・ランタン・溶岩などの光は、プレイヤーの周りのワールドをボクセルにして、その中で計算します  
光の色をボクセルの中で広げる floodfill は軽く、柔らかい間接光になります  
光源シャドウはピクセルごとに強い光源を選んでレイを飛ばし、影を付けます (重い)  
プロファイル「低」は floodfill だけで照らし、「中」から光源シャドウを使います

## よく触る設定

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| ブロックライトの明るさ (`BLOCKLIGHT_BRIGHTNESS`) | 1.0 | 0.1〜8.0 | 光源が周りを照らす強さ全体 |
| ブロックライトの暖かさ (`BLOCKLIGHT_WARMTH`) | 0.6 | 0.0〜1.0 | 0 は白に近い炎の色、1 はバニラのような橙 |
| ブロックライトの壁の照り返し (`BLOCKLIGHT_BOUNCE`) | 0.5 | 0.0〜4.0 | 壁の色が光に混ざる濃さ、赤い部屋なら光が赤みを帯びる、0 で照り返しなし |
| 光の揺らぎ (`LIGHT_FLICKER`) | ON | ON / OFF | 炎の光源をわずかに揺らす |

洞窟が暗いと感じたら、まず明るさを少し上げます  
動画を撮るときに揺らぎが気になれば OFF にします

## 光の届く距離

`LIGHT_FALLOFF_MODE` (既定「光の量」) で、光が遠くへどう弱まるかを選びます

- レベル: 光源レベルに比例して届き、端の手前で急に落ちます  
  マグマブロック・アメジスト・ロウソクのようなレベルの低い光源は、数ブロック先に光の円の縁が見えます
- 光の量: 明るさ x レベルの平方根に比例して届き、端までなめらかに暗くなるので縁が見えません  
  明るい光源の近くの明るさは、どちらでもほぼ同じです

「光の量」のときは、次の 4 つで届く距離 (ブロック) を決めます

| 設定 | 既定 | 範囲 |
|---|---|---|
| 主要な光源の届く距離 (`LIGHT_RANGE_MAJOR_MAX`) | 20.0 | 12〜32 |
| 主要な光源の届く距離の下限 (`LIGHT_RANGE_MAJOR_MIN`) | 12.0 | 4〜32 |
| 弱い光源の届く距離 (`LIGHT_RANGE_MINOR_MAX`) | 15.0 | 12〜32 |
| 弱い光源の届く距離の下限 (`LIGHT_RANGE_MINOR_MIN`) | 12.0 | 4〜32 |

主要な光源はたいまつ・ランタン・グロウストーン・シーランタン・フロッグライトなど、弱い光源は鉱石・アメジスト・マグマブロック・ヒカリゴケ・洞窟のツタ・溶岩・ポータルのように数が増えやすいものです  
距離を伸ばすと遠くの床や壁まで照らしますが、光源ごとに照らす範囲が広がって重くなります  
弱い光源は数が多いので、アメジストの晶洞やヒカリゴケの洞窟で特に重くなります

## ボクセル範囲

`VOXEL_VOLUME` は、光の広がりと光源シャドウを計算する、プレイヤーの周りの範囲です

| 値 | 範囲 (ブロック) |
|---|---|
| 0 | 128x64x128 |
| 1 | 192x96x192 |
| 2 (既定) | 256x128x256 |
| 3 | 384x128x384 |

範囲の外は、バニラのライトマップの明るさに戻ります  
大きいほど VRAM を使うので、足りないときは小さくします  
影の距離 (`shadowDistance`、[shadows-gi.md](shadows-gi.md)) は、範囲の半径 (64 / 96 / 128 / 192) 以上にしておきます  
この値を変えると全部のプログラムが作り直しになり、読み込みに時間が掛かります

## 色付き floodfill

`FLOODFILL` (既定 ON) は光源の色をそのまま広げるので、色付きガラスを通った光と合わさると部屋の色が混ざります  
「floodfill 間接光の強さ」(`FLOODFILL_STRENGTH`、既定 0.25、0.0〜2.0) は、光源シャドウが ON のときに floodfill を間接光として足す強さです  
光源シャドウが OFF のときは floodfill がそのまま全部の光になるので、この値は使われず、明るさは「ブロックライトの明るさ」で決まります

## 光源シャドウ

`LIGHT_SHADOWS` (既定 ON) を ON にすると、近くの強い光源をレイトレースして、ブロック・プレイヤー・エンティティが設置した光源の影を落とします  
OFF にするとこのパスごと止まって軽くなりますが、影のない floodfill だけの光になります

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| 設置光源の影の濃さ (`LIGHT_SHADOW_STRENGTH`) | 1.0 | 0.0〜1.0 | 0 で影なし、1 で完全な影 |
| 1 ピクセルあたりの光源数 (`LIGHT_TRACE_COUNT`) | 4 | 1〜16 | 影を付ける光源の数、増やすほどノイズが減って重くなる |
| トレース解像度 (`LIGHT_TRACE_RES`) | 1/2 | フル / 1/2 / 1/4 | 低いほど速く、ノイズが増える |
| ノイズ除去 (`LIGHT_DENOISE`) | 時間 + 空間 | なし / 時間 / 時間 + 空間 | 影のノイズをならす |
| 光源の大きさ (`LIGHT_SOURCE_SIZE`) | 0.5 | 0.0〜2.0 | 大きいほど影の輪郭が柔らかい |
| 光源の多い所の影の割り振り (`LIGHT_TRACE_SPLIT`) | OFF | ON / OFF | 当たる光源が光源数より多いピクセルで、特に明るい光源だけ毎回トレースする |
| ブロック形状の遮蔽 (`LIGHT_SHAPE_TRACE`) | ON | ON / OFF | ハーフブロック・フェンス・塀が実際の形で影を落とす |
| 光源の接触影 (`LIGHT_CONTACT_SHADOWS`) | ON | ON / OFF | ボクセルで表せない細部をスクリーンスペースの影で補う |

影がざらつく・ちらつくときは、ノイズ除去が「時間 + 空間」になっているかを見てから、光源数を増やすか、トレース解像度を上げます  
アメジストの群れのように同じ明るさの光源が並ぶ所のノイズには「光源の多い所の影の割り振り」が効き、重さは変わりません

### 光を遮るもの

| 設定 | 既定 | 変わるもの |
|---|---|---|
| エンティティによる遮蔽 (`LIGHT_ENTITY_OCCLUSION`) | ON | モブやブロックエンティティが光を遮る、影パスでエンティティを描くので重い |
| プレイヤーによる遮蔽 (`LIGHT_PLAYER_OCCLUSION`) | ON | 自分が光を遮る |
| エンティティ遮蔽の方式 (`LIGHT_OCCLUSION_MODE`) | 三角形 | ボクセルは 0.5 ブロックの箱で軽いが影が箱型、三角形はモデルの形どおり |
| エンティティ三角形の上限 (`LIGHT_ENTITY_TRIANGLES`) | 4096 | 2048 / 4096 / 8192 / 16384、うち 1024 は自分用 |

三角形の方式では、スケルトンの肋骨のような透明な部分は光を通します  
モブが多くて上限を超えると、超えた分は箱の影に戻ります  
箱の影が目立つなら上限を上げます (重くなります)

### 色ガラスと照り返し

| 設定 | 既定 | 範囲 |
|---|---|---|
| 色ガラスの色付け (`LIGHT_TRANSLUCENT_TINT`) | ON | ON / OFF |
| 色ガラスを通るブロックライトの色 (`LIGHT_TRANSLUCENT_TINT_SATURATION`) | 1.5 | 0.0〜3.0 |
| ブロックライトの鏡面反射 (`LIGHT_SPECULAR`) | ON | ON / OFF |
| 光るブロックの面の光り方 (`LIGHT_EMISSION_MASK_MODE`) | 面全体 | 面全体 / 光る範囲 / テクスチャのマスク |

色付けは色付きガラスのほか、氷・スライム・ハチミツにも掛かります (水は除く)  
色の濃さは 0 で色なし (暗くなるだけ)、1 でガラスの色で、どちらでも明るさはほぼ同じです

面の光り方は、シーランタンなどが周りを照らすときの光る形です  
「光る範囲」はテクスチャの明るい四角だけ、「テクスチャのマスク」は模様まで反映しますが、光るブロックの近くで重くなります

## 光源の上限

ネザーのグロウストーンの壁や光源だらけの街のように、光源が多すぎる場所のための設定です  
上限を超えない場面では、変えても見た目も重さも変わりません

| 設定 (内部名) | 既定 | 範囲 | 変わるもの |
|---|---|---|---|
| 上限を超えた時の光源の選び方 (`LIGHT_CULL_MODE`) | 明るさ x 近さ | 到着順 / 近い順 / 明るさ x 近さ | どの光源を残すか |
| 光源の総数の上限 (`LIGHT_MAX_COUNT`) | 4096 | 1024〜8192 | 1 フレームに直接光として扱う数、超えた分は遠い順に外れる (floodfill の光は残る) |
| ビンごとの光源の上限 (`LIGHT_BIN_LIGHTS`) | 64 | 16〜128 | 8x8x8 ブロックの区画 1 つに入る数、64 より上は VRAM を約 10 MB 多く使う |
| 光源の影のレイの長さ (`LIGHT_TRACE_STEPS`) | 96 | 48〜192 | レイが辿るブロック数、足りないと遠い光源の影が途中で切れて光が漏れる |
| 鏡面反射の光源数 (`LIGHT_SPECULAR_COUNT`) | 4 | 1〜8 | 少ないと、光源の多い床で照り返しが切り替わる線が見える |
| 接触影の光源数 (`LIGHT_CONTACT_SHADOW_COUNT`) | 4 | 1〜16 | 上げるほど重い |

選び方は既定の「明るさ x 近さ」のままで構いません  
外れる境目の光源は数フレームかけて弱めるので、歩いても入れ替わりが目立ちません  
「到着順」はフレームごとに違う光源が外れてちらつきます

光源が密集した場所のちらつきはまだ直っていません  
ビンごとの上限を上げると減りますが、1 ピクセルが調べる光源が増えて重くなります  
光源の多い場所で重いときに下げる順は [performance.md](performance.md) にあります

## 手持ち光源

| 設定 | 既定 | 範囲 |
|---|---|---|
| 手持ち光源 (`HAND_LIGHT`) | ON | ON / OFF |
| 手持ち光源の明るさ (`HAND_LIGHT_BRIGHTNESS`) | 1.0 | 0.1〜4.0 |
| 手持ち光源のレイ (`HAND_LIGHT_RAYS`) | ON | ON / OFF |
| 手持ち光源の接触影 (`HAND_LIGHT_SS_SHADOWS`) | ON | ON / OFF |
| 手持ち光源の影の濃さ (`HAND_LIGHT_SHADOW_STRENGTH`) | 0.6 | 0.0〜1.0 |

両手を別々の光源として扱い、壁にはボクセルのレイで、手や近くのモブにはスクリーンスペースで影を付けます  
影の濃さは 0 で影なし、0.6 で直接光の影が真っ暗になり、陰に照り返しが少し回り込みます  
0.6 より上は照り返しだけが減っていき、1 で手持ち光源の照り返しがなくなります

## エンティティ光源

`ENTITY_LIGHTS` (既定 ON) を切ると、下の 4 つがまとめて止まります

| 設定 | 光るもの |
|---|---|
| ドロップした光源アイテム (`ITEM_LIGHTS`) | 地面に落ちたたいまつや溶岩バケツ |
| 投擲物の光 (`PROJECTILE_LIGHTS`) | 光の矢・火の玉・花火 |
| 燃えるエンティティの光 (`BURNING_ENTITY_LIGHTS`) | 燃えているエンティティ |
| 発光エンティティの光 (`GLOWING_ENTITY_LIGHTS`) | ブレイズ・ヒカリイカ・マグマキューブ・エンドクリスタル・点滅中の TNT |

帯電クリーパーとウィザーの防壁の光は別で、`CHARGED_CREEPER_LIGHT` (既定 ON) と強さの `CHARGED_CREEPER_LIGHT_BRIGHTNESS` (既定 1.0、0.25〜2.0) で決めます  
floodfill の柔らかい光なので影は付かず、ほとんど重くなりません

## 鉱物ブロックの発光

`DECORATIVE_BLOCK_LIGHTS` (既定「光源」) で、ラピスラズリ・エメラルド・ダイヤモンド・金・レッドストーン・アメジストのブロックを光らせます

- OFF: バニラのまま
- 発光のみ: 表面だけ光り、周りは照らさない
- 光源: 鉱物の色のほのかな光で周りを照らし、影も落とす

ブロックごとのスイッチは、ラピスラズリ・エメラルド・レッドストーン・アメジストが ON、ダイヤモンドと金が OFF で始まります  
明るさは `DECOR_BRIGHTNESS` (既定 1.0、0.0〜3.0)、色の濃さは `DECOR_SATURATION` (既定 2.0、0.0〜2.0) で、色の濃さは 0 で白、1 で鉱物の色、2 で原色に近くなります

## 光源の見た目

「光源の見た目」の画面は、光源そのものが画面にどれだけ明るく写るかだけを決め、周りを照らす光は変えません  
たいまつが眩しいと感じたら、ここで下げます

| 設定 (内部名) | 既定 | 補足 |
|---|---|---|
| 光源のまぶしさ (`EMISSION_GLARE`) | OFF | 光る部分を 4 倍にして芯を白く飛ばし、あふれた分をブルームとレンズの効果に回す、光源を直に撮ったような見た目だがかなり目立つ |
| 発光の強さ (`EMISSION_STRENGTH`) | 1.0 | 光る部分の明るさ全体 (0.0〜8.0)、上げるほど芯が白く飛ぶ |
| たいまつの明るさ (`EMISSION_TORCH_BRIGHTNESS`) | 1.0 | 魂・レッドストーン・銅のたいまつも含む |
| 炎の明るさ (`EMISSION_FIRE_BRIGHTNESS`) | 1.0 | 火・魂の火・キャンプファイヤー・ロウソク |
| ランタンの明るさ (`EMISSION_LANTERN_BRIGHTNESS`) | 0.75 | 下げるほどテクスチャの模様が見える |
| 光源ブロックの明るさ (`EMISSION_BLOCK_BRIGHTNESS`) | 0.75 | グロウストーン・シーランタン・レッドストーンランプ・フロッグライトなど、下げるほど模様が見える |
| ビーコンの明るさ (`EMISSION_BEACON_BRIGHTNESS`) | 0.05 | ビームは遠くからも見えるので低め |
| 帯電クリーパー・ウィザーの防壁の明るさ (`EMISSION_CHARGED_CREEPER_BRIGHTNESS`) | 1.0 | 0 でバニラと同じ |
| クリーキングの目の明るさ (`CREAKING_EYE_BRIGHTNESS`) | 1.0 | 0 で光らない、周りは照らさない |
| ヒカリゴケの光 (`GLOW_LICHEN_LIGHT`) / 強さ (`GLOW_LICHEN_BRIGHTNESS`) | ON / 0.45 | OFF にすると光って見えるだけになる |
| ホタルの茂みの光の強さ (`FIREFLY_BUSH_BRIGHTNESS`) | 0.25 | 上げるほど遠くまで明るい |
| 開いたアイブロッサムの明るさ (`EYEBLOSSOM_BRIGHTNESS`) | 1.0 | 0 で光らない |
| ID の無い発光ブロックの光 (`GENERIC_LIGHT`) / 強さ (`GENERIC_LIGHT_BRIGHTNESS`) / 色 (`GENERIC_LIGHT_COLOR`) | ON / 1.0 / 炎 | MOD などの登録の無い発光ブロックを、発光レベル (2 以上) から光源にする。色は 1 色で、ブロックごとの色は出ない。登録済みのブロックは変わらない |

溶岩・ビーコンの光線・花火

| 設定 | 既定 | 補足 |
|---|---|---|
| 溶岩の明るさ (`LAVA_BRIGHTNESS`) | 5.0 | 1 までは濃い橙のまま明るくなり、1 を超えると淡い橙へ寄る、0 で持ち上げなし |
| 溶岩のブルーム (`LAVA_BLOOM`) | 0.25 | 溶岩の周りのにじみ、0 でほかの物と同じ |
| 溶岩の照らす光 (`LAVA_LIGHT`) | 2.0 | 周りの地形を照らす強さ、0 で照らさない |
| ビーコンの光線の散乱 (`EMISSION_BEACON_SCATTER`) | ON | ビームを大気で散乱する光として描く、昼は淡く夜ははっきり、OFF で一定の明るさの細い線 |
| ビーコンの光線のにじみ (`EMISSION_BEACON_SCATTER_STRENGTH`) | 1.0 | 霧・もや・雨の中でビームの周りがにじむ強さ |
| 花火の輝き (`FIREWORK_GLOW`) | ON | 火花などの光るパーティクルを色を保って明るくする |
| 花火の輝きの明るさ / 瞬き (`FIREWORK_GLOW_STRENGTH` / `FIREWORK_TWINKLE_STRENGTH`) | 1.0 / 0.3 | 瞬きは 0 で揺らがない |
| 花火の光 (`FIREWORK_LIGHT`) / 強さ (`FIREWORK_LIGHT_STRENGTH`) | ON / 1.0 | 開いた瞬間に周りを花火の色で照らす、影は付かず軽い |

## 光の計算の流れ

光源シャドウが ON のときの、1 フレームの中の流れです  
詳しい設計は [../architecture.md](../architecture.md) の「ブロックライト」にあります

| 手順 | 内容 | 関係する設定 |
|---|---|---|
| ボクセル化 | 地形を 1 ブロック 1 セルで書き込む、エンティティはモデルの三角形を書き (収まらない分は 0.5 ブロック単位の占有ビット)、光るエンティティは光源として登録する | `VOXEL_VOLUME`、`LIGHT_ENTITY_TRIANGLES` |
| floodfill | 光の色を 6 近傍へ 1 フレームに 1 ステップずつ広げて、間接光のもとにする | `FLOODFILL` |
| 光源の振り分け | すべての光源を 8x8x8 ブロックのライトビンに振り分ける | `LIGHT_MAX_COUNT`、`LIGHT_BIN_LIGHTS` |
| トレース | ピクセルごとに、所属するビンの光源を明るさで重み付けする、1 ピクセルあたりの光源数を N として、上位 N-1 個は必ずトレースし、残りから 1 個を明るさに比例した確率で選んでトレースする、選ばれなかった光源にも平均すると正しく影が付く、半影は光源の大きさの範囲で時間方向に揺らして作る | `LIGHT_TRACE_COUNT`、`LIGHT_SOURCE_SIZE` |
| ノイズ除去 | 再投影と近傍クランプ、エッジを保つ空間フィルタでならす | `LIGHT_DENOISE` |
| 合成 | 直接光、floodfill (間接光)、手持ち光源、鏡面反射をまとめて照らす | `FLOODFILL_STRENGTH` |

手持ち光源は二重に足されないよう floodfill には入れず、ピクセルごとに直接計算します

## まだできないこと

- 水やガラスのような半透明の面には、光源の影がまだ付きません  
  floodfill の光だけで照らすので暗めに見えます
- モッドの光源ブロックにはまだ対応していません
